📚 Digital Library — Python + Flask Web App

A simple and user-friendly Digital Library Web Application built using Python (Flask), where users can browse and view PDF notes of various subjects.
Designed for students who want quick and easy access to study material.

🚀 Features

✅ Clean and simple homepage
✅ Organized subjects
✅ PDF notes (download/view)
✅ Flask backend
✅ HTML & CSS frontend
✅ Easy to extend (add more subjects & PDFs)
✅ Lightweight & beginner-friendly

🛠️ Tech Stack

Technology	Purpose
Python	Main backend logic
Flask	Web framework
HTML	Page structure
CSS	Styling and layout

⚙️ How to Run This Project

1️⃣ Clone the repository
git clone https://github.com/Sarthakthakre18/website-using-python.git
cd website-using-python

2️⃣ Install dependencies
pip install flask

3️⃣ Run the Flask server
python app.py

4️⃣ Open the project in your browser
http://127.0.0.1:5000
